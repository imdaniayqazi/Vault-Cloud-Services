🚀 Just shipped my Cloud Computing semester project — Vault, a cloud-based file storage system!

As part of my BS coursework at Lahore Garrison University, I built a fully functional file storage app where users can sign up, upload, download, and manage their own files — all stored securely in the cloud, with a UI inspired by Google Drive.

🔧 Tech stack:
• Frontend: HTML, CSS, JavaScript
• Backend & Auth: Supabase (Postgres-based, open-source Firebase alternative)
• Cloud Storage: Supabase Storage buckets with row-level security policies
• Deployment: Netlify

💡 What it demonstrates:
✅ Storage-as-a-Service architecture
✅ User authentication & access control (each user only sees their own files)
✅ Real-time storage usage tracking
✅ Scalable cloud infrastructure — no servers to manage

This project really helped me understand how modern cloud platforms handle authentication, storage policies, and scalability behind the scenes — concepts that go way beyond just theory once you actually build something with them.

🔗 Try it live: https://vaultcloudservices.netlify.app
